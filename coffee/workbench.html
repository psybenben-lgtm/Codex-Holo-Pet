🔮 自制塑料瓶全息罩 & Pepper's Ghost 成像原理

利用 Pepper's Ghost（佩珀尔幻象）45° 光学虚像反射：透明梯形薄膜与手机屏幕呈 ~44.4°（约 45°） 夹角，将平放手机上的四面亮像素（黑底透光对比）反射汇聚成悬浮在金字塔中央的 3D 立体小人。

  • 选材：矿泉水瓶或透明饮料瓶中段平整无花纹透明壁（也可用透明 PVC 片 / 亚克力片）。
  • 裁切比例（4 片相同等腰梯形）：上底 1 cm · 下底 6 cm · 梯形高 3.5 cm，折叠粘合后高度约 2.45 cm、斜角恰为 44.4°！
  • 摆放要点：把梯形小口 (1 cm) 朝下倒扣放在手机屏幕正中心，关闭周围强顶灯，手机调高亮度并点击「⛶ 全屏清屏模式」效果最立体。

本项目所有计算与渲染100% 在您自己的电脑与局域网手机之间运行，绝不连接任何第三方服务器，代码全开源可审计：

  • 键盘节奏感应（可选，可一键关闭）：仅在「挖土罢工」模式下统计每秒按键次数，绝不记录、存储或发送具体字母与密码；点击「关读键盘·纯按钮」即彻底停用，用网页按钮一样触发全套挖土与搓澡流程。

🌐 局域网 Wi-Fi 配置与浏览器常见限制避坑

  • 为什么必须连同一 Wi-Fi？手机端通过局域网 HTTP + SSE 长连接直连电脑 29765 端口。校园网/公司公共 Wi-Fi 常开启「AP 客户端隔离」导致手机扫不通电脑——可改为家用路由器 Wi-Fi，或直接用手机开个人热点让电脑连上即可。
  • Clash / VPN 虚拟 IP 踩坑：开着代理工具时系统可能出现 198.18.* 虚拟网卡。如遇手机打不开，请在上方 IP 下拉框切换为 192.168.* 真实无线网卡 IP，或关闭 TUN 代理模式。
  • Windows 防火墙拦截：首次运行若弹出 Windows 安全警报，请务必同时勾选「专用网络」和「公用网络」并点击允许，放行 Python 29765 端口。
  • 浏览器声音与传感器限制如何避免？ 1) iOS Safari/安卓浏览器禁止网页未点击自动播声音——进入手机页后轻触一次画面或点击「开启声音」即解锁； 2) 现代浏览器禁止在非 HTTPS 局域网地址里直接调手机陀螺仪或手机摄像头——因此本项目把摄像头识别留在电脑本机（127.0.0.1 安全上下文），而手机端采用「触控左滑倾倒 / 滑条 / 按钮」做零证书免报错的流畅交互，无需折腾根证书也能 100% 玩透！
